# fdm-print-optimisation.md — slicer-level knobs for waste, strength and quality, each one PROVEN from the sliced output

Owner (2026-09-30): *"purge into infill is an optimization to reduce waste that the skill can use. there are also other possible strength and
quality knobs you can use to optimize."* This is the one home for slicer-side optimisation; the geometry rules stay in
`references/dfm-printed-enclosure.md` §8 and the kit mechanics in `references/print-kit.md` — both link here, neither repeats a row.

**The rule.** Every knob used is set in the plate yaml (`design/bambu_plates.yaml` or the project's equivalent — per plate, or per object through
the per-object overrides the CLI honours, `dfm-printed-enclosure.md` §8.3), is recorded in the `.3mf.json` sidecar and drift-checked against the
3MF's embedded `project_settings.config` / `model_settings.config` (`print-kit.md` §5), and is **proven from the g-code / slice report, never from
the yaml**: the "how proven" column names the derived row (`purge_g`, `tower_g`, `support_g`, `print_time_s`, `wall_loops` read back, a feature
count inside an object footprint). A knob without its proof row is a wish. Kickoff **C11** (`kickoff.enclosure.optimise`: *speed / strength /
surface / minimal waste*) selects the default knob set (§4); every deviation per plate is a yaml line with the reason.

Key names are Bambu Studio's (02.08 / 2.x); PrusaSlicer's equivalents in brackets where they differ. Sources: Bambu Lab Wiki pages fetched
2026-09-30 **[V]** (`reduce-wasting-during-filament-change`, `parameter/prime-tower`, `parameter/ironing`, `parameter/elephant-foot`,
`parameter/strength-advance-settings`, `parameter/quality-advance-settings`, `parameter/fuzzy-skin`, `parameter/line-width`,
`parameter/filament-sequence-for-different-layers`, `wall-generator`, `xy-hole-contour-compensation`, `sequent-print`, `slow-down-for-overhang`,
`Seam`, `support`, `modifier`), Prusa Knowledge Base **[V]** (`infill_42`, `infill-patterns_177130`, `layers-and-perimeters_1748`, `ironing_177488`,
`seam-position_151069`, `arachne-perimeter-generator_352769`, `elephant-foot-compensation_114487`, `fuzzy-skin_246186`, `sequential-printing_124589`).
A row marked **[K]** is practice or the source project's measurement (labelled), not a published page. Pages move (the Bambu wiki 404s for most
guessed URLs — the live index is `wiki.bambulab.com/en/bambu-studio/parameter`); re-fetch before quoting a number.

## 1. Waste (multi-colour plates and single-filament plates)

| Knob | What it buys | What it costs | When it applies | How it is PROVEN | Keys |
|---|---|---|---|---|---|
| **Flush into infill** | the purge of a colour change goes into sparse infill instead of the chute — the wiki's own example cut a tower from 14.76 g to 9.05 g by moving the changes down, and infill flushing removes the chute volume on top **[V]** | the odd-coloured infill can show through light / transparent filaments and through thin shells (1 wall + few shell layers) — the wiki warns of it **[V]**; so: purge the darker-after-lighter direction only into regions that are not seen, keep `wall_loops` ≥ 3 and shells ≥ 4 over flushed infill | **only when the colour change happens at layers that HAVE sparse infill** — a 2-layer bed-face colour mark (`dfm-printed-enclosure.md` §8.1 b) changes filament at layers 1–3 where there is no infill: it gains NOTHING, state that in the plate record; a body whose change sits above ~layer 10 with 15–20 % infill does gain | `purge_g` (= filament used − part volume × density for the solid colour mark) and `tower_g` from `slice_info.config` / the g-code `M620` count, compared with the SAME plate sliced chute-only; the sidecar row `flush_into_infill: true` and the colour-change layer index ≥ the first infill layer | `flush_into_infill`, `flush_into_support` (default on **[V]**), `flush_into_objects` [Prusa: *Wipe into this object's infill / Wipe into this object*] |
| **Flush volume calibration per filament pair** | the default table "errs on the side of quality"; a 0.8–0.9 multiplier or a per-pair edit saves purge on every change **[V]** | too low = discoloured layers (the wiki's picture); dark→light pairs need the most | every multi-colour plate; calibrate once per filament pair on a coupon, record the pair values | `flush_volumes_matrix` / `flush_multiplier` in the sidecar; `purge_g` before / after on the same plate | `flush_volumes_matrix`, `flush_multiplier` [Prusa: *Purging volumes*] |
| **Prime tower width / prime volume** | less tower per layer (Bambu 2.0 moved prime volume to the FILAMENT settings — set it per filament **[V]**) | a thin tower topples on a tall plate; the tower must still reach the highest colour-change layer | multi-colour plates with changes high up: put the changes LOW (orientation) first — the tower stops where the changes stop **[V]** | `tower_g`; tower height = highest change layer in the sliced preview | `prime_tower_width`, `prime_volume` (filament), `enable_prime_tower` |
| **Prime tower OFF on single-filament plates** | zero tower | none | every plate with one filament — the source project's default plates (worked example) **[K]** | `tower_g` 0; `enable_prime_tower: false` in the embedded config | `enable_prime_tower` |
| **Colour changes grouped on few layers** | every layer that holds two colours is a filament change pair (a two-filament plate is not "two colours without swaps") — grouping the coloured features into one Z band cuts the change count in proportion **[K, source project]** | geometry: colour only in one Z band per part (`case-pipeline.md` Presets) | every AMS plate | `M620` count in the g-code (= changes), per-plate | `other_layers_print_sequence` (Auto minimises swaps and flush per layer **[V]**), `first_layer_print_sequence` |
| **Print by object (sequential)** | less travel → less stringing / oozing; one object's failure spares the others **[V]** | collision rules: objects ≥ `extruder_clearance_max_radius` apart; the first-printed object's height ≤ `extruder_clearance_height_to_rod` when another object shares its Y band; the prime tower cannot be used in by-object mode **[V]** | coupon plates and small single-filament parts; never with an AMS tower | the embedded `print_sequence: by object`; object order in `model_settings.config` | `print_sequence` [Prusa: *Complete individual objects*] |
| **Reduce infill retraction** | fewer retractions inside infill = time and less wear | stringing inside the part (invisible) | sparse-infill-heavy bodies | `print_time_s` before / after | `reduce_infill_retraction` |

## 2. Strength

| Knob | What it buys | What it costs | When it applies | How it is PROVEN | Keys |
|---|---|---|---|---|---|
| **Wall loops** | strength comes mostly from the perimeters, not the infill (Prusa) **[V]**; 4 loops at 0.42 = the 1.6 wall rule of the home preset (`dfm-printed-enclosure.md` §8) | time, mass | every structural body; bosses and latch roots | `wall_loops` read back from the embedded config; the census wall row on the mesh (geometry side) | `wall_loops` [Prusa: *Perimeters*] |
| **Wall sequence** | `inner/outer` (default) best for overhangs — the inner wall carries the outer; `outer/inner` crisper surface, seam more visible; `inner/outer/inner` best outer finish on thick walls **[V]** | overhang quality vs surface | legend / mark faces: `inner/outer/inner`; overhanging bodies: `inner/outer` | `wall_sequence` in the config | `wall_sequence` [Prusa: *External perimeters first*] |
| **Infill pattern + density** | gyroid: equal strength in every direction, no self-crossing in a layer; cubic / adaptive cubic: ~¼ less material than rectilinear at equal top support, denser near the walls; 100 % forces rectilinear **[V]** | time; adaptive cubic has large central cavities (fine for a case shell) | shells and trays: gyroid 15–20 %; bosses: see modifiers; never `sparse_infill_density: 100%` on the CLI (rc −18, §8.3) — a solid column is `top_shell_layers` / `bottom_shell_layers` | `sparse_infill_pattern` / `sparse_infill_density` in the config; `filament_g` | `sparse_infill_pattern`, `sparse_infill_density` [Prusa: *Fill pattern / density*] |
| **Shell layers vs thickness** | top shell ≥ recess depth + 1.0 under an ironed mark (§8.1 a); ≥ 3 bottom / 5 top layers at 0.20 is the profile default **[V, Bambu profiles]** | time, mass | every top face that is seen; every rebate / recess floor | `top_shell_layers`, `top_shell_thickness` read back; rule Z of `print_dfm.py` on the MESH | `top_shell_layers`, `top_shell_thickness`, `bottom_shell_layers` |
| **Modifier meshes for local strength** | 100 % infill or +walls only around inserts, screw bosses, magnet pockets, latch roots — a modifier is any mesh placed over the model with its own settings **[V]**; GENERATE the modifier bodies from the same yaml features (boss positions, pocket positions) so they move with the geometry | one more object per modifier in the 3MF; per-object settings must be written into `model_settings.config` (the CLI honours them, §8.3) | every boss carrying an insert or a magnet; the latch root of a compliant arm | the modifier's footprint in the plate json and a feature count (solid infill lines) inside it vs the same object sliced without | `Add modifier` → per-object `sparse_infill_density`, `wall_loops` |
| **Orientation vs load** | layer lines perpendicular to the load path: across-layer strength is 30–50 % lower (`dfm-printed-enclosure.md` §8 anisotropy) **[physics]** | the orientation also decides supports, overhangs and the top face — one choice serves several rules | bosses under screw preload, cantilever latches, pillar ends | the auto-orientation row + the steepest-overhang row per orientation (§8.5); FEA with the anisotropy factor | (geometry, not a slicer key) |
| **Outer-wall speed and cooling** | slower outer wall + enough cooling = better layer adhesion and overhangs; `slow_down_for_overhang` grades wall segments by overhang degree and slows only those **[V]** | time | overhanging bodies; PETG / ASA walls | `outer_wall_speed`, `overhang_*_speed` in the config; `print_time_s` | `outer_wall_speed`, `slow_down_for_overhang`, `overhang_1_4_speed` … |
| **Enclosure / chamber** | PETG / ASA warp and layer splitting fall with a closed chamber **[physics]** | PLA needs the door open or it softens | PETG / ASA plates; the ENV record says which printer | the filament profile's `chamber_temperature` / bed type; the warp row on the first article | `chamber_temperatures`, `curr_bed_type` |
| **Infill / wall overlap** | the infill is widened into the inner wall ("riveting"); default 15 %, 50 % bulges the surface, negative leaves a gap **[V]** | surface bulge when too high | structural bodies: 15–25 %; mark faces: default | `infill_wall_overlap` in the config | `infill_wall_overlap` |
| **Bridge flow / thick bridges** | lower bridge flow and thin bridges sag less under a plate land (§8.4) | a thin bridge is weaker — only where a land sits on it | every bridged strip under a glued plate; the dust-cap tip face | `bridge_flow`, `thick_bridges: false` read back (the source project's default **[K]**) | `bridge_flow`, `thick_bridges` |

## 3. Quality and accuracy

| Knob | What it buys | What it costs | When it applies | How it is PROVEN | Keys |
|---|---|---|---|---|---|
| **Arachne wall generator** | variable-width perimeters: thin walls, text and small logos print without gap fill; `detect_thin_wall` is moot under Arachne **[V]** | fewer predictable widths — the census reads the MESH, not the line count | legend plates, marks, thin features | `wall_generator: arachne` in the config; the mark coupon | `wall_generator`, `min_feature_size`, `min_bead_width` [Prusa: *Perimeter generator*] |
| **Precise outer wall** | the outer wall keeps its nominal width → dimensional accuracy of the outside | slightly different inner-wall spacing | fit surfaces on the outside (lap skirts, cap mouths) | `precise_outer_wall` read back; the first-article caliper table | `precise_outer_wall` |
| **Elephant-foot compensation** | shrinks the first-layer contour so it matches the layers above; ~0.2 at a 0.4 nozzle (Prusa default) **[V]**; **per object** (a flange on the bed needs it, a text plate not) | the brim does not touch the part (by design); thin first-layer features are protected from over-shrink **[V]** | mating skirts, cap flanges (§8.2: 0.15 + 0.5 mm first-layer lines), plate rebates — on BOTH parts of a fit (§8.4 working clearance ≥ 0.1 after EF) | layer-1 outer-wall CONTOUR of the object vs the same object sliced alone (orientation-agnostic — the arranger may rotate it 90°); a layer-1 vs layer-2 bbox delta cannot separate EF from a chamfer or a sole round **[K, source project]** | `elefant_foot_compensation` (sic) [Prusa: *Elephant foot compensation*] |
| **XY hole / contour compensation** | holes print under nominal (shrink + squish): hole compensation widens holes only; contour compensation moves the outer size only **[V]**; coupon-decided per filament and profile | a global number cannot serve a 2 mm pin hole and a 20 mm bore alike — per-preset `fits` knobs in the geometry are the primary route (§1.4), these keys the secondary | fit holes (inserts, magnets, pins) when the geometry knob is exhausted | `xy_hole_compensation` / `xy_contour_compensation` in the sidecar; the caliper table | `xy_hole_compensation`, `xy_contour_compensation` |
| **Seam position / scarf seam** | `back` hides the seam on a display face; `aligned` on cylinders; `nearest` on parts with corners; a scarf joint overlaps start and end to hide the seam on smooth perimeters **[V]**; staggered inner seams make the part stronger (Prusa) **[V]** | `random` scatters zits; a seam on a legend face is a defect (§8 seam rule) | every body with a legend face: `back` or painted away from it | `seam_position` in the config; the seam paint in `model_settings.config` | `seam_position`, `seam_gap`, `seam_slope_type` (scarf) [Prusa: *Seam position, Scarf joint*] |
| **Ironing** | smooths top faces by a second low-flow pass at the same Z; `top` irons ALL top surfaces — **never `topmost`** (it irons only the highest face and skips a recess floor, §8.1 a) **[V]**; ~+5 min on a small plate | time; heat creep on long PLA ironing; soft edges; useless on curved tops **[V]** | marked top faces; glue faces that must be flat (Prusa) | `ironing_type: top` read back; the mark coupon | `ironing_type`, `ironing_flow`, `ironing_spacing`, `ironing_speed`, `ironing_pattern` (Bambu 2.x adds concentric / Archimedean) |
| **Variable layer height** | finer layers only where the surface slopes; fewer stairs on a dome, no time penalty on the vertical walls | a per-object height profile the sidecar must carry | domes, lead-in cones, the cap's closed end | the layer-height profile in `model_settings.config`; `print_time_s` | *Variable layer height* (GUI / `layer_height_profile`) |
| **Only one wall on top** | one wall on top surfaces → the ironing / top pattern reaches the edge, better flat tops **[V]** | a thin top edge | ironed mark faces | `only_one_wall_top` read back | `only_one_wall_top`, `top_one_wall_type` |
| **Gap fill / thin-wall detection** (classic generator) | closes gaps between perimeters; prints single-line walls | under Arachne both are moot **[V]** | classic generator only | config keys present only when `wall_generator: classic` | `gap_infill_speed`, `detect_thin_wall` |
| **Fuzzy skin** | a rough side texture that hides layer lines and seams and adds grip — on outer walls / contour only, never on fit faces or top / bottom (walls only by construction) **[V]**; apply by PAINT or a MODIFIER to a grip zone, not globally | dimensional accuracy of the fuzzed face (± thickness); a fit face must stay smooth | the grip band of a cap or a hood lift; never a lap | `fuzzy_skin` + `fuzzy_skin_thickness` / `fuzzy_skin_point_distance`; the painted region in `model_settings.config` | `fuzzy_skin` (contour / contour and hole / all walls), `fuzzy_skin_thickness`, `fuzzy_skin_point_distance` |
| **Support interface and tree-support tuning** | a dedicated support filament on the INTERFACE only (Bambu Support for PLA / PETG; PETG and PLA support each other) gives a clean underside at low cost **[V]**; tree supports for interior cavities | an AMS slot; interface filament under a visible face still leaves a scar on a down-face — the geometry rule (no supports on visible faces, §8) stands | interior supports of a shell; never a visible face | `; FEATURE: Support` extrusions inside the outer-wall hull only (the g-code read of §8); `support_g` | `support_type`, `support_interface_filament`, `support_style`, `tree_support_*` |
| **Brim / mouse ears for warp** | holds a tall or thin-footed part; `auto-brim` by object **[V]** | the brim mark on the first layer; a brim on a fit flange changes the EF reading | pillars, tall thin bodies, PETG | `brim_type` / `brim_width` read back; the first-article warp row | `brim_type`, `brim_width`, `brim_object_gap` |
| **Per-object overrides** | every key above per object in one plate — the CLI applies `<metadata key= value=>` under `<object>` in `model_settings.config` (supports, ironing, top shell, EF, first-layer line width proven **[K, source project]**); the arranger re-places a generic 3MF, so positions are read BACK from the exported plate json | tagging the file as a Bambu project (`Application=BambuStudio-<ver>`) segfaults the CLI (rc −11) **[K]** | mixed plates: a coupon beside a case piece | the exported plate json footprints + feature points inside them | `Metadata/model_settings.config` object metadata |

## 4. Default knob sets per kickoff answer (C11 `kickoff.enclosure.optimise`)

| Answer | Set (every key in the plate yaml, every row proven) |
|---|---|
| **speed** | `wall_loops` 3, gyroid 10 %, no ironing, `print_sequence: by layer`, `reduce_infill_retraction` on, `enable_prime_tower` off on single-filament plates |
| **strength** | `wall_loops` 4–5, gyroid or cubic 20–25 %, modifiers at 100 % around inserts / bosses / magnet pockets / latch roots, `wall_sequence: inner/outer`, `infill_wall_overlap` 25 %, orientation by load, `slow_down_for_overhang` on |
| **surface** | `wall_sequence: inner/outer/inner`, `seam_position: back` (or painted), `ironing_type: top` on marked faces, `only_one_wall_top`, Arachne, `precise_outer_wall`, variable layer height on domes |
| **minimal waste** (RECOMMENDED when an AMS plate exists) | colour changes grouped low and in one Z band, `flush_into_infill` + `flush_into_support` on bodies whose changes sit above the first infill layer (stated per plate when they do not), flush multiplier calibrated per pair, `prime_tower_width` minimal, `other_layers_print_sequence: auto`, `enable_prime_tower` off on single-filament plates, purge grams reported per plate against the chute-only slice |

The chosen set is the plate yaml's `optimise:` block; a plate that departs from it carries the reason on the line. The sidecar carries every key the
set names; the kit text gate (`print-kit.md` §3) fails a START_HERE that claims a saving the sidecar does not show.
